Conexión Online Gratuita (Supabase)

Actualmente la app guarda datos en tu navegador (Modo Local). Conéctala a tu proyecto gratuito de Supabase para trabajar en línea desde cualquier celular o PC.

Resumen del Paso a Paso para activar Supabase gratis:
  1. Crea una cuenta gratuita en supabase.com y crea un proyecto nuevo.
  2. Ve a SQL Editor en Supabase, pega el contenido del archivo supabase-schema.sql y presiona Run.
  3. Ve a Project Settings → API, copia tu Project URL y anon public key, y pégalos arriba.
  4. Presiona Subir Comandas Locales a Supabase para migrar tus registros ZRA-286 a ZRA-290.
